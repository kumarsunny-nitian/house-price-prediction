# 🏠 House Price Prediction using Linear Regression

## 🚀 Live Demo

**Deployed Application:**
https://sunny-house-price-prediction.streamlit.app/

## 📌 Overview

This project predicts house prices using Machine Learning. A Linear Regression model is trained on housing data and deployed using Streamlit for real-time predictions.

## ✨ Features

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature Scaling
* Linear Regression Model
* Model Evaluation
* Streamlit Web Application
* Live Cloud Deployment

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* GitHub

## ▶️ How to Run Locally

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Streamlit application

```bash
python -m streamlit run app.py
```

### 3. Open your browser and visit

```text
http://localhost:8501
```
