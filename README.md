# House Price Prediction using Linear Regression

## Overview

This project predicts house prices using Machine Learning. A Linear Regression model is trained on housing data and deployed using Streamlit for real-time predictions.

## Features

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Linear Regression Model
* Model Evaluation
* Streamlit Web Application

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit

## Project Structure

House_Price_Prediction/

├── app.py

├── requirements.txt

├── README.md

├── data/

├── models/

└── House_Price_Prediction.ipynb

## How to Run

1. Install dependencies:

pip install -r requirements.txt

2. Run the Streamlit application:

python -m streamlit run app.py

3. Open your browser and visit:

http://localhost:8501
